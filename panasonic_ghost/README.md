# panasonic_ghost

Konfiguracja dla Panasonica CF-SV z Hyprlandem.

## Programy

| Program | Rola |
|---------|------|
| **hyprland** | compositor / window manager |
| **waybar** | pasek statusu |
| **foot** | terminal |
| **fuzzel** | launcher aplikacji |
| **yazi** | menadżer plików (TUI, w terminalu) |
| **nvim** | edytor tekstu |
| **mako** | powiadomienia |
| **hyprpaper** | tapeta |
| **hypridle** | zarządzanie idle (wygaszanie ekranu) |
| **hyprlock** | blokada ekranu |
| **hyprshot** | zrzuty ekranu |
| **cliphist** | historia schowka (wl-paste) |
| **pavucontrol** | graficzne sterowanie dźwiękiem |
| **wpctl** | sterowanie głośnością z klawiatury (PipeWire) |
| **playerctl** | sterowanie odtwarzaczem z klawiszy media |
| **brightnessctl** | jasność ekranu z klawiszy Fn |
| **power-profiles-daemon** | profile zasilania (performance / balanced / power-saver) |
| **hyprpolkitagent** | agent polkit (autoryzacja GUI) |
| **WireGuard** | VPN (przez NetworkManager / nmcli) |

## Skróty klawiszowe (główne)

| Skrót | Akcja |
|-------|-------|
| `Super + Return` | terminal (foot) |
| `Super + D` | launcher (fuzzel) |
| `Super + E` | menadżer plików (yazi) |
| `Super + L` | blokada ekranu (hyprlock) |
| `Super + Q` | zamknij okno |
| `Super + V` | tryb pływający |
| `Super + F` | pełny ekran |
| `Super + H/J/K/L` | nawigacja między oknami (vim-style) |
| `Super + 1-9` | przełącz workspace |
| `Super + Shift + 1-9` | przenieś okno na workspace |
| `Print` | screenshot całego ekranu |
| `Super + Print` | screenshot okna |
| `Super + Shift + S` | screenshot zaznaczonego obszaru |
